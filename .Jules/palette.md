## 2026-09-30 - Modal Dialog Keyboard Dismiss & Accessible Trigger Pattern
**Learning:** Custom vanilla HTML modal dialogs often only bind click handlers to close buttons, leaving keyboard users trapped or forced to tab to the close button, and missing expected overlay-click dismiss behavior. Furthermore, custom interactive controls rendered as `div` (such as the interactive gift box) must explicitly declare `role="button"` and `tabindex="0"`, listen for both `Enter` and `Space`, and prevent page scroll on `Space`.
**Action:** When working with vanilla JavaScript modals and custom interactive elements in this app, ensure all modal overlays have `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, and synchronize `aria-hidden` when toggling. Implement a central Escape key listener and backdrop click handler, and ensure interactive container elements support standard keyboard activation.
